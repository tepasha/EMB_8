## Підключення

Піни задаються на початку `src/main.c`:

| Сигнал         | GPIO (за замовчуванням у коді) |
|----------------|---------------------------------|
| OLED SDA (I2C) | GPIO8                           |
| OLED SCL (I2C) | GPIO9                           |
| BME280 MOSI    | GPIO11                          |
| BME280 MISO    | GPIO13                          |
| BME280 SCLK    | GPIO12                          |
| BME280 CS      | GPIO10                          |
| DS18B20 DATA   | GPIO4 (+ підтягуючий резистор ~4.7кОм до 3.3В) |
